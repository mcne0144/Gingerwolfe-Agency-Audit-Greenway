# Sibling video creative briefs

**Status:** INTERNAL — reshootable creative briefs, not client-facing. Nothing here goes to a GM or the client without Shannon McNeil's approval.
**Prepared:** 2026-08-29, Content Strategist lane.
**Companion to:** `../SIBLING_SOCIAL_ANALYSIS_2026-08-29.md` (§7 repurposing playbook). Each brief maps back to the §7 rows it feeds.

## Method

1. Videos downloaded directly from tiktok.com on 2026-08-29 (this environment has direct TikTok network access; no Apify usage consumed).
2. Each video was reviewed as 12–16 evenly spaced still frames plus the post's own metadata (caption, sticker text, duration, public stats) parsed from the TikTok page JSON.
3. **Audio was not transcribed** (no speech-to-text run). Spoken dialogue is described only where on-screen captions or visual context make it certain. Nothing quoted as dialogue is invented; where wording is unknown the brief says so.
4. Public stats were re-retrieved 2026-08-29 and match the sibling analysis doc within normal drift (like/share/save counts moved by tens since the Apify pull).

## Rules that apply to every brief (from OPERATING_RULES.md and PILLARS.md)

1. Formats are copied, footage never is. Every reshoot uses the pilot store's own lot, own stock, own people.
2. Every vehicle shown must be verifiably on that store's lot. No forward-model titling.
3. Every offer is real, store-confirmed, full disclaimer in the caption.
4. Named staff need two independent sources before a name enters client-facing copy.
5. Sibling stores are internal benchmarks, never framed as rivals to a pilot GM.
